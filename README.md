# nestdaq-rawdata-tools
NestDAQ raw data tools

## How to install
```
cd <A directory where you want to install this tools>
git clone https://github.com/spadi-alliance/netdaq-rawdata-tools
cd nestdaq-rawdata-tools
make
```

## How to use it
```
cd <A directory where you want to install this tools>/nestdaq-rawdata-tools
./rawdata-dumper <data directory>/tdc/data/00/run00000XX.dat

etc...
```
